# 💼 Personal Portfolio

A modern and responsive personal portfolio website built using **React.js, Vite, Tailwind CSS, Framer Motion, and GSAP**. It showcases my projects, technical skills, certifications, internship experience, and contact information with a clean and interactive user interface.

## ✨ Features

- Responsive design for all devices
- Modern and interactive user interface
- Smooth animations using GSAP and Framer Motion
- Projects showcase with live demo and GitHub links
- Skills and technology section
- Internship and certification details
- Contact section with social media links
- Fast performance with Vite

## 🛠️ Tech Stack

- React.js
- Vite
- Tailwind CSS
- JavaScript
- HTML5
- CSS3
- GSAP
- Framer Motion

## ▶️ Installation

```bash
npm install
npm run dev
```
